# HomeworXX conceptsite

Conceptontwerp van een nieuwe website voor HomeworXX (huiswerkbegeleiding en bijles, Zutphen), gemaakt door [Chris Kokkeler](https://chriskokkeler.com).

Dit is **geen officiële website** van HomeworXX. Teksten, prijzen en citaten komen van de huidige site. Het contactformulier verstuurt niets en de site staat op noindex.

Stack: Astro (statisch), zelfgehoste lettertypen (Fraunces, Figtree), geen trackers.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # output in dist/
```
